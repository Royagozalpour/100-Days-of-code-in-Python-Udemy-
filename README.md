## 📚 Course Overview

This challenge is based on the Udemy course by Dr. Angela Yu. It covers:

- 🧠 Python fundamentals
- 🎮 Game development with Turtle & Tkinter
- 🌐 Web development with Flask
- 📊 Data analysis & visualization
- 🤖 Automation & scripting
- 🔗 APIs & web scraping
